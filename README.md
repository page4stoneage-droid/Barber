💈 Barber Shop Management System
A simple, lightweight, and clean Command-Line Interface (CLI) application to manage user registration, authentication, and appointment booking for a barber shop.


✨ Features
User Registration: Secure sign-up with password length validation (min 8 characters).
Secure Authentication: Passwords are hidden during input using the getpass module.
Session Management: Users must be logged in to book an appointment.
Appointment Booking: Prevents double-booking (no two users can take the same time slot).
Clean UI: Clear screen functionality for a neat and user-friendly CLI experience.
OOP Structure: Built using Object-Oriented Programming principles for better maintainability.

🛠️ Tech Stack
Language: Python 3.x
Modules Used: os, getpass (Standard Python Libraries - No extra installation needed!)

🚀 How to Run
1.Make sure you have Python 3 installed on your system.
2.Clone or download this repository.
3.Open your terminal or command prompt.
4.Navigate to the project folder.

Run the following command:
python barber_shop.py

📋 Usage Guide
Run the program.
Choose 1 to register a new account (password must be 8+ characters).
Choose 2 to log in using your credentials.
Choose 3 to book an appointment (you must be logged in!).
Choose 4 to exit the system.
